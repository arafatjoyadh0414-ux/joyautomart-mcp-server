JOY Automart MCP Server

Give AI assistants and agents live access to JOY Automart's automotive parts catalogue and JOY Auto Exchange vehicle listings in Bangladesh, with prices in BDT, stock, chassis fitment, comparisons and auctions.

https://www.joyautomart.com/mcp

Endpoint

URL
https://www.joyautomart.com/mcp
Transport
Streamable HTTP (JSON-RPC 2.0 over POST). This is not the legacy SSE transport. Use "type": "http" / streamable-http in your client.
Protocol version
2025-03-26
Server
joy-automart v1.2.0
Authentication
None needed for the public, read-only tools. A buyer token is optional (see below).

Quick test

curl -s -X POST https://www.joyautomart.com/mcp \\
  -H 'Content-Type: application/json' \\
  -H 'Accept: application/json, text/event-stream' \\
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'

Vertex AI Agent Builder (ADK, Python)

In Google's Agent Development Kit, attach the server as an MCP toolset, then deploy the agent to Vertex AI Agent Engine:

from google.adk.agents import Agent
from google.adk.tools.mcp_tool.mcp_toolset import MCPToolset, StreamableHTTPConnectionParams

agent = Agent(
    model="gemini-2.5-flash",
    name="joy_automart_assistant",
    instruction="Help buyers find car parts and vehicles from JOY Automart.",
    tools=[MCPToolset(connection_params=StreamableHTTPConnectionParams(url="https://www.joyautomart.com/mcp"))],
)

OpenAI Responses API

from openai import OpenAI
client = OpenAI()
resp = client.responses.create(
    model="gpt-4.1",
    tools=[{
        "type": "mcp",

    input="Find front brake pads for a Toyota Axio NZE161 under 5000 BDT",

print(resp.output_text)

Tools

ToolWhat it doesArguments
search_partsSearch JOY Automart's automotive parts catalogue in Bangladesh. Accepts English, Bangla (e.g. 'টয়োটা এক্সিও ব্রেক প্যাড') or Banglish. Returns retail prices in BDT, availability and a product URL. Results are fitment candidates, not guarantees.query, make, chassis, category, in_stock_only, max_price_bdt, page, page_size
get_partFull public detail for one catalogue part: BDT price, stock, minimum order, verified offers and bulk price breaks.part_id
search_vehiclesSearch JOY Auto Exchange vehicle listings in Bangladesh by make, model, year, fuel and BDT price. Only stated listing facts are returned.query, make, fuel_type, verified_only, min_year, max_year, min_price_bdt, max_price_bdt, sort, page, page_size
get_vehicleFull public detail for one JOY Auto Exchange listing (by listing id or slug): BDT price, specs, photos and, when the car passed JOY's human QC, a summary of the inspection. Only stated listing facts are returned; seller contact details and reserves are never exposed.vehicle_id
get_auction_statusPublic status of one live or recent JOY auction: current bid in BDT, bid count, end time and anti-snipe extensions. Observation only: bidding needs a verified dealer account and a human. The seller's reserve and bidder identities are never shown. Returns an error while live auctions are not open.auction_id
compare_vehiclesSide-by-side comparison of 2 to 4 listings (ids or slugs from search_vehicles): price, year, mileage, fuel, verification and inspection grade. Listings that cannot be found are reported, not hidden.vehicle_ids
get_buying_guideHow to buy from JOY Automart: currency (BDT), payment methods (card, bKash/Nagad/Rocket, cash on delivery), Dhaka and nationwide delivery zones and fees, human contact, and how an authenticated agent can place orders.—
prepare_buyer_handoffCompose the links a human buyer uses to complete a purchase: the product page and a pre-filled WhatsApp message to JOY's sales team. Creates nothing and charges nothing.part_id, quantity, vehicle, note

Authentication & buyer tokens

All the tools above work anonymously. To act on behalf of a signed-in JOY buyer, create a personal agent token at My account → AI agents. Tokens start with joyagt_.

Send the token as an HTTP header: Authorization: Bearer joyagt_…. If you use the npm proxy, set JOY_AGENT_TOKEN instead. Treat tokens like passwords: never paste them into shared configs or public repositories. You can revoke a token at any time on the same page.

The server never takes payments. prepare_buyer_handoff returns a product link and a pre-filled WhatsApp message, so a human buyer always completes the purchase.

Fitment caveat

Fitment results are guidance, not a guarantee. Compatibility comes from catalogue data such as chassis codes and OEM numbers. Model years, grades and the Japanese-import variants common in Bangladesh can differ. Agents should tell users to confirm the chassis code (for example NZE161) or the OEM part number with JOY's sales team before they buy. Vehicle details are only those stated in the listing, plus JOY's human QC summary where one exists.
